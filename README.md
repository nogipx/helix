# Quantum Realms / Terminal Hack

Играбельный браузерный прототип по `../game_concept.md` и `../game_lore.md`.

Требуется Node.js 18+. Без сборки и установки зависимостей:

```sh
npm start
```

Открыть http://127.0.0.1:4173. Проверка механики: `npm test`.

## Как играть

Войти с перехваченным токеном, выбирать соседние узлы на карте, выполнять `scan`, отключать защиту через `breach КОД`, скачивать архивы командой `siphon`. Для победы нужен хотя бы один архив и команда `extract`. Главная цель — `quantum.shard` в ядре. Два боковых хранилища дают дополнительную добычу.

`phantom` один раз снижает тревогу на 30%; `scrub` снижает на 18%, забирает 8 секунд и восстанавливается 25 секунд. Копирование длится 5 секунд и усиливает трассировку. Каждые 30 секунд проходит AI-патруль. При 100% тревоги, истечении 180 секунд или трёх ошибках входа данные теряются. После победы следующая операция усиливает пассивную трассировку.

Команды доступны кнопками. В терминале работают история ↑/↓ и автодополнение Tab. Рекорд сохраняется в localStorage. Звук включается отдельно. Интерфейс работает на телефоне и компьютере. Google Fonts необязателен: предусмотрены системные шрифты.

Это локальная симуляция взлома. Репутация, постоянные улучшения, другие классы агентов и сюжетная кампания пока не реализованы.
