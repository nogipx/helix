# Quantum Realms / Terminal Hack

Браузерная игра по [концепту](docs/game_concept.md) и [лору](docs/game_lore.md). [Аудит геймдизайна](GAME_DESIGN_AUDIT.md) описывает изменения, проверки и ограничения.

Node.js 18+, без зависимостей и сборки:

```sh
npm start
```

Открыть http://127.0.0.1:4173. Проверки: `npm test`. Модель баланса: `npm run simulate`.

## Правила

Войти с перехваченным токеном и выбрать соседний узел. `scan` раскрывает ICE-задачу: четыре кандидата и проба с числом совпадений **по позиции**. `breach КОД` с верным ответом открывает канал; ошибка добавляет 14% тревоги. Повтор отклонённого ответа не штрафуется. `overload` позволяет пропустить задачу за 22% тревоги.

`connect УЗЕЛ` перемещает по карте. Закрытый ICE блокирует продвижение, но позволяет отступить на посещённый узел. Обратный путь через открытые узлы стоит меньше тревоги.

`siphon` копирует архив; длительность и шум зависят от его ценности. `abort` отменяет передачу, не сохраняя частичный архив. После кражи нужно вернуться в **GATEWAY** и выполнить `extract`. Достаточно любого архива; `quantum.shard` — основная цель с дополнительными очками. Только доставка Shard повышает следующий сектор.

`phantom` один раз снижает тревогу на 30%. `scrub` снижает её на 18%, тратит восемь секунд времени сети (включая патрули) и восстанавливается 25 секунд. Взлом SENTINEL однократно снижает тревогу на 22%. Каждые 30 секунд патруль добавляет 7%. При 100% тревоги, истечении 180 секунд или трёх ошибках входа данные теряются.

Очки: MB + 500 за Shard + оставшиеся секунды, только после эвакуации. Рекорд хранится в localStorage.

Команды доступны кнопками. История: ↑/↓, автодополнение: Tab. Звук включается отдельно. `help` — справка. Кнопка «Новый забег» предлагает подтвердить сброс командой `restart`.

Приватная локальная игра: публикация не нужна. Google Fonts необязателен, предусмотрены системные шрифты. Репутация и постоянные улучшения пока не реализованы. Правила четырёхсекторного забега описаны ниже.

## Рогалик: «Украденные демоны»

Теперь операции объединены в забег из четырёх секторов. После Shard выбирай одного из трёх демонов с преимуществом и побочным эффектом — или уходи с накопленными очками. Поражение уничтожает весь буфер забега. HELIX отвечает на стиль игры контрмерами, схемы сети меняются, новые аномалии взаимодействуют со сборкой. В финале перед вскрытием ядра нужен боковой архив с подписью HELIX.

Полные правила и ограничения: [ROGUELIKE.md](ROGUELIKE.md). Модель четырёхсекторного забега: `npm run simulate:campaign`. Перезагрузка страницы начинает новый забег; сохраняется только рекорд. Описание одиночного сектора выше остаётся базовым: демоны и условия сектора меняют указанные цены.

## История и результаты

Терминал имеет ограниченную высоту: история прокручивается внутри, задача и ввод остаются рядом. Если читать старые записи, новые сообщения не сбрасывают позицию; кнопка «Новые сообщения» возвращает к концу. Подробный пример ICE открывается в отдельном окне.

Кнопка «Результаты» открывает последние 50 завершённых забегов: дата, исход, очки, достигнутый сектор и сборка. Журнал сохраняется в браузере через localStorage; промежуточный выбор демона не считается завершённым результатом. Досрочный выход, итоговая победа и поражение записываются один раз. Незавершённый забег при перезагрузке по-прежнему сбрасывается.
