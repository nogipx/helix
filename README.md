# Quantum Realms / Terminal Hack

Полноэкранная браузерная игра про разведку сетей, кражу данных и сборку агента на один забег. Основа: [концепт](docs/game_concept.md) и [лор](docs/game_lore.md). Актуальные правила экспедиции: [ROGUELIKE.md](ROGUELIKE.md).

Node.js 18+, без зависимостей и сборки:

```sh
npm start
```

Открыть http://127.0.0.1:4173. Тесты: `npm test`. Модели фиксированных стратегий: `npm run simulate` и `npm run simulate:campaign`.

## Первый контракт

1. До `login` зайди в магазин. Стартовый кошелёк — 120 Cr, в комплект помещаются три заряда.
2. Авторизуйся перехваченным токеном. Таймер начинается после входа.
3. Выполни `recon`: изначально известен только GATEWAY. Разведка открывает соседние адреса, но не их роль и содержимое.
4. `connect АДРЕС` подключается к обнаруженному соседу. `scan` раскрывает тип узла, добычу и ICE-задачу. Сравни четыре кандидата с пробой: нужен вариант с точным числом совпадающих символов **на тех же позициях**.
5. `breach КОД` решает ICE. `overload` обходит задачу за тревогу. Для разведки следующих маршрутов сначала нужно открыть текущий узел.
6. `siphon` копирует найденный архив. `abort` прерывает передачу без сохранения части архива.
7. Вернись в GATEWAY и выполни `extract`. Покупатель платит за доставленные данные; остаток времени не превращается в деньги.

После Shard выбери следующий контракт, докупи расходники и установи одного из предложенных демонов — либо закончи экспедицию. Сеть, её расположение и условия следующего сектора изменятся, открывать карту нужно заново.

## Снаряжение

| Команда | Цена | Эффект одного заряда |
|---|---:|---|
| `use sniffer` | 35 Cr | Маршруты и классы узлов за известной границей; архивы и ICE скрыты |
| `use emp` | 70 Cr | Открыть текущий ICE без тревоги; печать ядра остаётся |
| `use tunnel` | 80 Cr | Эвакуация с добычей из любого открытого узла |
| `use patch` | 50 Cr | Восстановить одну единицу целостности |

Магазин доступен до авторизации и после эвакуации. Купленные заряды сохраняются в комплекте, использованные не восстанавливаются между секторами. При провале или прерывании активной экспедиции весь комплект теряется. Уже выплаченные кредиты защищены.

## Маскировка и поражение

`phantom` снижает тревогу на 30% **один раз за всю экспедицию**. `scrub` снижает на 18%, тратит восемь секунд времени сети и восстанавливается 25 секунд. Взлом SENTINEL однократно снижает тревогу на 22%. Базовый патруль каждые 30 секунд добавляет 7%; контрмеры и демоны меняют эти параметры.

Целостность нейроинтерфейса — 3/3 на весь забег. Новый неверный ICE-кандидат даёт −1 целостности и +14% тревоги; повтор отклонённого ответа бесплатен. На нуле целостности, при 100% тревоги, истечении времени либо трёх ошибках авторизации экспедиция заканчивается. Текущие данные, сборка и инструменты теряются. Доставленные раньше данные уже оплачены.

## Управление и сохранение

Кнопки выполняют те же команды, что терминал. История ввода: ↑/↓, автодополнение: Tab. Страница не прокручивается, история терминала прокручивается отдельно и не сбрасывает позицию при новых сообщениях. На телефоне карта и терминал доступны вкладками. На компьютере есть кнопка «На весь экран».

Кошелёк, неиспользованные инструменты в безопасной фазе и последние 50 результатов сохраняются в localStorage. Перезагрузка во время активной экспедиции считается её прерыванием: комплект теряется, кошелёк остаётся. Текущая карта и сборка не восстанавливаются. Старые записи с очками остаются в журнале с прежней единицей измерения; новые содержат выручку в Cr.

Игра работает полностью в браузере, включая сохранения. Google Fonts необязателен: предусмотрены системные шрифты. Это короткий прототип; цены и баланс требуют человеческого плейтеста.

## Публикация в GitHub Pages

[CI](.github/workflows/pages.yml) запускается на PR и push в `main`: проверяет синтаксис модулей и выполняет тесты. После успешной проверки `main` публикует каталог `dist` через официальный Pages artifact/deploy workflow. Установка пакетов и сборка не нужны — игра не имеет npm-зависимостей. Доступен ручной запуск через Actions → Test and deploy Pages → Run workflow.

Домен: `helix.nogipx.dev`, сохранён в `dist/CNAME`. В Settings → Pages источником должен оставаться GitHub Actions. Workflow использует штатный `GITHUB_TOKEN` и OIDC; отдельные секреты не нужны. Права публикации получает только deploy job, PR выполняет проверки без публикации. Версии actions закреплены SHA.
